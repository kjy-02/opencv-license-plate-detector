# 샘플 이미지

`01.png`, `02.png`, `03.jpg`, `04.jpg`, `05.jpg`, `06.jpg`는 전공 수업 발표에 사용한 차량 이미지입니다.

2026-10-23 프로젝트 작성자가 직접 제작한 발표자료와 그 안의 이미지·페이지를 이 저장소에서 재사용하도록 제공했습니다. 기존 발표자료에는 직접 촬영 이미지와 인터넷 수집 이미지가 함께 사용됐다고 기재되어 있으며, 이미지별 촬영자와 원본 URL은 추후 기록할 수 있습니다.

동일한 기본 설정의 결과와 실패 사례는 상위 README에 기록되어 있습니다. `scripts/generate_demo.py`로 결과를 재생성할 수 있습니다.
