# 발표자료

`project-report.pdf`는 작성자가 제작한 시스템프로그래밍 기말 프로젝트 최종 발표자료입니다. 전체 25쪽을 보존하고, 저장소 설명에 필요한 7개 페이지를 PNG로 발췌했습니다.

| 파일 | PDF 페이지 내용 |
| --- | --- |
| `page-05.png` | 전체 알고리즘 흐름 |
| `page-07.png` | 전처리 효과 비교 |
| `page-11.png` | GUI 구성과 조작 |
| `page-16.png` | 코드 구조 개선 |
| `page-19.png` | 정면·기울어진 번호판 실험 |
| `page-20.png` | 복잡한 배경·저조도 실험 |
| `page-21.png` | 지하주차장·큰 기울기 실험 |

페이지 번호는 PDF의 물리적 순서입니다. 당시 실험 화면은 이미지별 수동 파라미터 조정 기록이며, 현재 기본값 실행 결과와 구분합니다. 자세한 설명은 [개발 기록](../PROJECT_NOTES.md)에 정리했습니다.
