# 프로젝트 개발 및 실험 기록

시스템프로그래밍 전공 수업의 개인 과제로 진행한 번호판 영역 검출 프로젝트입니다. 이 문서는 작성자가 제작한 발표자료와 보관된 코드를 바탕으로 구현 선택과 실험 과정을 다시 정리합니다. 발표 PDF는 공개 저장소에 포함하지 않습니다.

## 프로젝트 목적

차량 전면·후면 이미지에서 번호판 영역을 선택하고, 기울기를 보정한 이미지를 추출하는 것이 목적입니다. 주차 관리나 차량 식별에서 OCR에 앞서 사용하는 영역 검출 단계를 학습 대상으로 삼았습니다. 실제 주차 관리 시스템과 OCR 기능은 구현 범위에 포함하지 않습니다.

번호판에는 비슷한 크기의 문자들이 가로로 배열된다는 특징이 있습니다. 사각형 모양만 찾으면 라이트·범퍼와 혼동할 수 있어 문자 후보의 크기, 간격, 정렬, 기울기를 함께 비교하는 구조를 사용했습니다.

## 처리 과정과 파라미터 실험

전체 처리 흐름은 README의 Mermaid 다이어그램으로 정리했습니다. 전처리 비교에는 슬라이드 전체 대신 원본·CLAHE·이진화·Morphology 이미지 4개만 사용했습니다.

`PlateParams`에 파라미터를 모으고 GUI에서 이진화, 후보 면적, 종횡비 등을 바꾸도록 연결했습니다. 중간 영상과 후보 개수, 선택 점수를 함께 확인하면서 어떤 처리 단계에서 오검출이 발생하는지 관찰할 수 있습니다.

현재 Morphology Close는 비교 화면을 위한 계산입니다. 문자 후보는 `prep["adaptive"]`에서 추출하므로 Morphology 결과를 검출 입력으로 사용하는 것으로 설명하지 않습니다.

## 코드 구조 개선

영상처리와 GUI 이벤트를 역할별로 분리했습니다.

| 파일·클래스 | 역할 |
| --- | --- |
| `main.py` | 파일 선택, 슬라이더 입력, 결과 표시·저장 연결 |
| `plate_gui.py` | PySide6 화면 구성 |
| `plate_detector.py` | 전처리, 문자 그룹화, 후보 점수화, 영역 추출 |
| `PlateParams` | 검출 파라미터 관리 |

화면 이벤트와 영상처리를 나누면 GUI 변경이 검출 함수에 직접 섞이지 않고, `process_image()`를 GUI 없이 호출해 샘플별 결과를 확인할 수 있습니다. 현재 시연 재생성 스크립트도 이 함수를 호출합니다. 발표자료의 Before 코드는 구조 설명용 예시이며 실행 가능한 과거 버전의 소스는 별도로 보관되어 있지 않습니다.

## 개발 중 해결한 문제

| 문제 | 적용한 방법 | 현재 범위 |
| --- | --- | --- |
| 한글 경로에서 이미지 읽기 | NumPy로 바이트를 읽고 `cv2.imdecode`로 디코딩 | 코드에 반영 |
| 슬라이더 입력마다 즉시 재처리 | 단발성 QTimer로 마지막 입력 후 150ms에 처리 | 처리 요청을 줄이며, 영상처리는 여전히 GUI 스레드에서 실행 |
| 처리 단계별 결과를 확인하기 어려움 | 결과 모드 선택과 검출 정보 표시 | Gray·CLAHE·이진화·후보 결과 등을 비교 가능 |

ChatGPT를 알고리즘 검토, 코드 분리, 오류 분석, 발표자료 구성에 활용했습니다. 생성된 제안을 실행 결과와 비교하며 수정한 개인 과제입니다.

### 수동 조정으로 얻은 결과와 기본값 결과의 차이

GUI 캡처에는 설정을 조절해 번호판을 추출한 예시와 큰 기울기에서 실패한 예시가 함께 있습니다. 현재 코드와 동일한 버전인지, 모든 파라미터가 무엇이었는지는 별도 실행 기록으로 확정하지 않았습니다.

현재 기본값 실행에서는 05번이 번호판을 선택했고, 02번은 일부가 잘렸으며, 01·03·04·06번은 다른 영역을 선택했습니다. [현재 실행 결과](../README.md#현재-코드-실행-기록)를 함께 남겨 조건 차이를 드러냈습니다.

## 성능 수치의 범위

당시 발표자료에는 10장 기준 50%→80%, 장당 평균 오검출 4.2→1.1개라는 개선 수치가 있습니다. 당시 평가 데이터 10장 전체와 정답 영역, 비교 코드, 판정 기준이 함께 보관되어 있지 않아 현재 저장소의 재현된 성능으로 제시하지 않습니다.

GUI 화면에 표시되는 후보 점수 역시 정답일 확률을 뜻하지 않습니다. 후보 선택용 휴리스틱 점수입니다.

## 후속 개선

- 이미지별 설정을 JSON으로 저장하고 다시 불러와 당시 실험 조건을 재현
- 반복 무늬·차량 그릴·배경 글자에 대한 오검출을 줄이도록 후보 순위 개선
- 정답 번호판 영역과 IoU를 비교하는 평가 구성
- 처리 작업을 GUI 스레드와 분리하여 화면 응답성 개선

## 자료 구성

PPTX에 포함된 원본 캡처와 전처리 이미지만 `images/`에 추출했습니다. 화면 이미지는 그대로 유지하고 설명은 README와 이 문서에 맞게 작성했습니다. PDF, PPTX 및 전체 슬라이드 이미지는 로컬에 보관하며 공개 저장소에는 포함하지 않습니다. 이미지의 슬라이드 대응은 [이미지 안내](presentation/README.md)에 정리했습니다.
